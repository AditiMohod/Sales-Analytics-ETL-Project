📊 End-to-End Sales Analytics Pipeline using Python, MySQL & Tableau

📌 Project Overview

This project demonstrates an end-to-end Sales Analytics pipeline built using Python, MySQL, SQL, and Tableau. The project extracts raw sales data from a CSV file, cleans and transforms it using Python (Pandas), loads the processed data into a MySQL database, and creates an interactive Tableau dashboard to analyze business performance.

🎯 Objectives

Build an ETL pipeline using Python
Clean and transform raw sales data
Store cleaned data in MySQL
Perform SQL-based business analysis
Create an interactive Tableau dashboard
Generate actionable business insights
